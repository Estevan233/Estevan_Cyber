# Estevan Cyber「混合工作室」首页改版设计

日期：2026-08-12  
状态：待用户确认  
目标仓库：`Estevan233/Estevan_Cyber`  
目标分支：`codex/hybrid-studio-homepage`

## 1. 背景与目标

现有首页已经具备清晰的技术主题，但大面积深色、网格背景和偏安全工具的视觉语言，让普通访客容易把它理解成“黑客工具站”，而不是一个可长期阅读的个人空间。本次保留 Hugo + PaperMod，不迁移 WordPress，不照搬 Akina/Joe3；只借鉴优秀个人博客的信息组织方式，完成一套更轻、更暖、同时保留技术辨识度的首页。

验收目标：

- 首屏让普通访客在 5 秒内看懂“这是 Estevan 的技术与生活记录”。
- 默认明亮、阅读优先；夜间模式继续可用，但不以纯黑和霓虹制造压迫感。
- 首页同时提供文章入口、当前关注、时间进度、标签导航和轻量音乐。
- 所有新增内容可通过 YAML 手动维护，不需要引入后台或数据库。
- 保持现有文章、搜索、站内问答、项目、工具和关于页面的 URL 与功能不变。

## 2. 已确认方向

### 2.1 视觉方向：D3 Adaptive Evening

- 默认主题为明亮模式。
- Hero 使用一张真实感的暖色夜间工作台图：台灯、笔记本电脑、书本、少量绿植和窗外蓝调夜景；不出现连帽人、终端代码墙、霓虹骷髅等廉价“赛博”符号。
- 内容区使用白色和浅灰背景，正文为近黑色，主色为低饱和青绿色，强调色少量使用暖琥珀色。
- 卡片圆角不超过 8px；不做嵌套卡片，不使用一整页漂浮面板。
- 深色模式使用深灰蓝而非纯黑，保留暖色图片和足够的正文对比度。

### 2.2 定位与文案

主标题：`Estevan Cyber`  
副标题：`技术、生活与仍在进行的实验。`  
辅助说明：`记录 AI Agent、云端实践、个人项目，也记录它们之外的日常。`  
主操作：`阅读文章`、`看看项目`、`站内问答`

语气保持克制、个人化，不写营销口号，也不向访客解释基本界面操作。

## 3. 页面结构

从上到下分为六个区域：

1. **现有导航栏**：保留首页、文章、搜索、问答、项目、工具、关于和主题切换。
2. **全宽 Hero**：背景为暖色工作台图片，文字直接叠加在图片上；首屏仍露出下一段内容，避免 Hero 吞掉整页。
3. **主页内容网格**：桌面端为 `最新文章 2fr + 侧栏 1fr`，移动端改为单列。
4. **侧栏功能**：当前关注、年度进度、标签云、音乐播放器，均为独立模块，不嵌套。
5. **当前设施**：保留 Hugo、Knowledge Agent、Tools、VPS Lab 四个入口，改成紧凑的横向信息带。
6. **页脚**：沿用 PaperMod，不新增无意义装饰。

### 3.1 最新文章

- 展示最新 5 篇文章，而不是现有 3 篇。
- 每篇展示标题、摘要、日期、阅读时长和最多 2 个标签。
- 有封面图时显示清晰缩略图；无封面图时采用纯文本布局，不使用占位图。
- 整张文章行可点击，键盘焦点清晰。

### 3.2 当前关注

通过 `data/focus.yaml` 手动维护 3 项：

1. 个人网站体验升级
2. Knowledge Agent 检索质量
3. Oracle Cloud 稳定性观察

每项包含标题、简述、状态和可选链接。状态只使用“进行中 / 观察中 / 待整理”三类，避免做成假装精密的项目管理面板。

### 3.3 时间进度

- 仅展示今日、本周、本月、今年四条进度。
- 浏览器按访客本地时间计算，不上传任何数据。
- 页面加载时计算，跨分钟刷新；不做出生倒计时。
- 使用原生 `progress` 或带 `aria-valuenow` 的等价可访问组件。

### 3.4 标签云

- 从 Hugo `site.Taxonomies.tags.ByCount` 自动生成，最多 18 个标签。
- 字号按文章数量分 3 档，避免无限缩放造成视觉噪声。
- 每个标签都是可访问链接；无标签时整个模块不渲染。

### 3.5 首页音乐

- 首页侧栏提供可折叠播放器，默认收起且绝不自动播放。
- 首期自托管 3 首 CC0 音乐，用户后续只需改 `data/playlist.yaml` 和替换音频文件。
- 候选曲目：`calm theme`（pebonius）、`Contemplation`（Joth）、`Chill lofi inspired`（omfgdude）。三者的 OpenGameArt 页面均明确标记 CC0。
- 同一时间只播放一首；切歌会停止上一首。离开首页后播放停止，不引入 PJAX 或全站悬浮播放器。
- 音频使用 `preload="metadata"`，不预下载全部文件；播放器提供播放/暂停、上一首、下一首、进度和音量。
- 仓库新增 `THIRD_PARTY_NOTICES.md`，记录曲名、作者、来源页、原始文件名、许可证与下载日期。即使 CC0 不强制署名，也保留来源链路。

Hero 原图由图像生成工具生成，并在 Hugo 构建时输出适配尺寸；实际模板提供宽高和响应式候选，避免首屏布局跳动。音频文件不做 Git LFS，首期总容量控制在约 10 MB 内。

## 5. 行为与异常处理

- `focus.yaml` 缺失或为空：隐藏当前关注模块，构建不失败。
- `playlist.yaml` 缺失或为空：隐藏音乐模块。
- 单个音频加载失败：显示该曲目不可用，允许用户切换下一首，不让播放器脚本报错终止。
- JavaScript 禁用：文章、当前关注和标签仍可阅读；时间进度显示静态占位说明；音频使用原生控件作为可用降级。
- 图片加载失败：保留可读 Hero 文案与纯色背景，不显示破图图标。
- 尊重 `prefers-reduced-motion`，动画仅使用短距离位移和透明度，关闭后完全静止。

## 6. 性能、安全与可访问性

- 不新增第三方前端框架、远程字体、统计脚本或播放器依赖。
- Hero 只加载首屏所需响应式图片；文章缩略图懒加载。
- 音频无自动播放，避免移动网络被悄悄吃掉。
- 所有按钮具有可读名称和明显焦点态；颜色对比目标为 WCAG AA。
- 外部链接沿用安全的 `rel` 设置；YAML 文本交由 Hugo 模板转义，不拼接未可信 HTML。
- 桌面与移动端均不得出现横向滚动、文字裁切或播放器控制重叠。

## 7. 验证与上线

实现后执行：

1. Hugo production build，无模板错误和 broken reference。
2. 以 1440×900 和 390×844 两个视口验证首页。
3. 同时检查明亮/深色模式、菜单、文章链接、问答入口和播放器。
4. 验证无自动播放；只请求当前选中曲目的 metadata/音频。
5. 将现网截图、目标视觉稿和本地实现截图放在同一对比画面中做视觉复核。
6. 检查生成页面无密钥、令牌、VPS 密码和私人路径泄露。
7. 完成后提交到 `codex/hybrid-studio-homepage` 并推送 GitHub；不直接覆盖 `main`，先通过 PR 审阅。

## 8. 非目标

- 不迁移到 WordPress、Halo、Akina 或 Joe3。
- 不改 Knowledge Agent API、模型、API Key 或 VPS 部署架构。
- 不实现评论、登录、朋友圈、相册、留言板或 PJAX。
- 不部署 Hermes、代理节点或新的后端服务。
- 本阶段不自动合并 PR，也不直接切换生产环境。

## 9. 成功标准

- 首页默认明亮，视觉上不再像“黑客控制台”。
- Hero 清楚展示 Estevan Cyber 这个主体，并具备真实、暖和、可辨认的工作台图片。
- 五个核心功能在桌面和手机均可使用：文章浏览、当前关注、时间进度、标签导航、音乐播放。
- 现有文章、项目、搜索、问答和工具入口无回归。
- 后续修改关注项和歌单不需要改 HTML 或 JavaScript。
